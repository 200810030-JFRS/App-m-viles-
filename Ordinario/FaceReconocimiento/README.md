# Actividad React Native: Cámara y Detección de Rostros

## Instalación y Ejecución
1. Abrir una terminal dentro de esta carpeta (`CamaraRostroRN`).
2. Instalar las dependencias:
   ```bash
   npm install
   ```
3. Iniciar el proyecto:
   ```bash
   npx expo start
   ```
4. Escanear el código QR con la app **Expo Go** en tu teléfono físico o presionar `a` para abrir en emulador Android.
