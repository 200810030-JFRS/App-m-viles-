# 📱 Repositorio de Aplicaciones Móviles #

En este repositorio se encuentran organizadas las prácticas, ejercicios y proyectos desarrollados durante la asignatura.

## 📂 Índice de Proyectos

* [Animated](./Animated) - Ejercicio sobre el uso de animaciones e interacciones.
* [Calculadora_IMC](./Calculadora_IMC) - Aplicación para el cálculo del Índice de Masa Corporal utilizando componentes de entrada y estado.
* [ConsumeAPI_MongoDB](./ConsumeAPI_MongoDB) - Conexión e integración de la app con API REST y base de datos MongoDB.
* [DinamicFlatList](./DinamicFlatList) - Manejo de listas dinámicas optimizadas con el componente `FlatList`.
* [DrawerNavigation](./DrawerNavigation) - Implementación de menú lateral desplegable (Drawer Navigator).
* [Ejercicio_03] - Listas con FlatList y SectionList; ImageBackground e Image
* [Ejercicio_01] - Componentes y props
* [Ejercicio_04] - Modal reutilizable con el texto capturado
* [Ejercicio_02] - Flexbox, TextInput y ScrollView; DemoChildren y FlagComponent
* [Ejercicio_05] - Continuación del ejericio 4.
* [Ejercicio_10] - Ejercicio de memorama.
* [Life](./Life) - Proyecto de minijuegos e interacción en React Native.
* [Mapas](./Mapas) - Integración de mapas e interactividad de geolocalización.
* [Sensores](./Sensores) - Uso e integración de sensores del dispositivo móvil (acelerómetro, giroscopio, etc.).
* [StackNavigation](./StackNavigation) - Navegación entre pantallas mediante pilas de rutas (Stack Navigator).
* [TabNavigation](./TabNavigation) - Navegación por pestañas inferiores (Bottom Tabs).
